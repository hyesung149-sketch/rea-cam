# REA Cam

개인용 실시간 뷰티 카메라 웹앱입니다. 폰 크롬에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

- 실시간 카메라에 피부 보정 · 얼굴(눈 크게, 갸름하게) · 메이크업(립, 블러셔) · 필터 12종 · 편집을 바로 적용
- 얼굴 자동 인식: MediaPipe Face Landmarker를 기기 안에서 실행 (사진은 서버로 전송되지 않음)
- 앨범 사진 보정, 비율(3:4 · 1:1 · 9:16 · 원본), 타이머, 좌우 반전, 갤러리, 공유

모든 코드는 직접 작성한 클린룸 구현이며 다른 앱의 코드나 리소스를 포함하지 않습니다.
